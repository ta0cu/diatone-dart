# diatone

A small music theory library for Dart — work with notes, scales, and chords.

Ported from the original Ruby [diatone](https://github.com/ta0cu/diatone-ruby) module.

## Features

- **Notes** — convert between note names, ordinals (MIDI-style), and frequencies
- **Scales** — major and minor scales from any tonic
- **Chords** — triads, sevenths, extensions, sus, dim, aug, and more

## Installation

Add to your `pubspec.yaml`:

```yaml
dependencies:
  diatone:
    path: ../diatone
